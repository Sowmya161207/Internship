## 👩‍💻 About This Repository

Welcome to my Python Internship Journey!

This repository contains the projects and practical exercises I developed on **Day 1** of my internship. The main goal was to strengthen my Python programming fundamentals and learn the basics of Git and GitHub.

## 📌 Projects

### 1. 🤖 Interactive Greeting Bot

A simple interactive Python application that welcomes users and provides personalized greetings.

**Features:**
- Accepts the user's name.
- Displays a personalized greeting.
- Interacts with the user through input and output.
- Provides a friendly user experience.

**File:** `greeting_bot.py`

### 2. 🧮 Menu-Driven Calculator

A Python-based calculator that performs basic arithmetic operations using a menu-driven approach.

**Features:**
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Modulus
- 🔢 Floor Division
- Handles division-by-zero errors.
- Allows users to perform multiple calculations until they choose to exit.

**File:** `calculator.py`

## ▶️ How to Run

**Step 1:** Clone the repository.

```bash
git clone YOUR_REPOSITORY_URL
```

**Step 2:** Navigate to the project folder.

```bash
cd internship
```

**Step 3:** Run the Greeting Bot.

```bash
python greeting_bot.py
```

**Step 4:** Run the Calculator.

```bash
python calculator.py
```

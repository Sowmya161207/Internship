## 💻 Practical Projects

### 1. 🤖 Console Chatbot

**File:** `chatbot.py`

A simple interactive chatbot that communicates with users through the console.

**Features:**
- Responds to user messages using keyword matching.
- Stores predefined replies in a dictionary.
- Maintains conversation history using a list of dictionaries.
- Continues chatting until the user types `bye`.

### 2. 📊 Student Marks Calculator

**File:** `student_marks.py`

A Python program that calculates important statistics from a list of student marks.

**Features:**
- Calculates average marks.
- Finds the highest marks.
- Finds the lowest marks.
- Uses functions and Python built-in methods.
